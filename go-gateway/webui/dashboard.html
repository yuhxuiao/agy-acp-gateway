接入与路由说明
每个账号在容器内使用独立的目录、出口代理与后台进程; 进行中的多轮对话固定留在原账号, 避免跨号重放历史触发风控并保住缓存。客户端可直接填主管理 Key 走全局分配, 或使用分组专属 Key / <主Key>@group:<分组ID>、单号专属 Key / <主Key>@<账号ID>, 以及请求头 X-Agy-Group / X-Agy-Account。
